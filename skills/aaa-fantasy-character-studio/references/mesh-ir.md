# MeshIR v1: native compiler contract

Run in verified agent cloud: `python scripts/native_mesh.py project/source/character.json project/export/character.glb --report project/evidence/compiler.json`. No pip packages or network required. Preserve JSON, authored geometry algorithms and texture files as editable source. The fixture `assets/mesh-fixture.json` is a tiny non-character regression case. Never use it as a human base or visual benchmark.

## Input fields
- version: 1; axes: Y_UP_Z_FORWARD_METERS. Mesh coordinates are meters, Y up, +Z forward. Use agreed character height and locked reference cameras.
- materials: unique id; optional base_color RGBA linear factors [0,1], metallic and roughness [0,1], double_sided, alpha_mode OPAQUE/MASK/BLEND, alpha_cutoff. textures mapping relative PNG/JPEG paths rooted at IR directory: base_color, orm (glTF R=AO/G=roughness/B=metal), normal, ao (overrides ORM occlusion), emissive. Use explicit material factors appropriate to maps; author images separately. No generated/baked maps are implied by this compiler. UV coordinates are glTF UV convention (0,0 top-left); account for texture orientation when authoring.
- joints (optional): parent-before-child unique id, parent null or earlier id, local translation XYZ. One root. Bind rotations/scales are identity. Author bone positions in character coordinates via parent-local offsets. For more complex bind transforms use an independently tested richer backend.
- parts: stable unique id, material id, kind mesh or loft. Mesh requires positions XYZ, faces ordered index triples or convex ordered quads, UV per vertex [0,1], optional weights per vertex mapping joint id to positive normalized value (1-4 influences). Split vertices intentionally for UV seams or hard normals. Optional smooth_seams pairs of coincident duplicated vertex indices (each appears once). Lofts accept rings of equal length, 3+ explicit points, ordered corresponding cross-sections, optional reverse_winding and ring_weights. Ring seam duplication creates UVs; lofts are open-ended unless separately authored caps are included. Default winding depends on authored order; verify outward normals. Use explicit mesh for anatomically coherent end caps, branch junctions, face loops and complex surfaces. Source quads remain in JSON; GLB triangulates deterministically.
- animations optional: list name and tracks, joint id, path rotation (normalized XYZW quaternion) or translation (parent local XYZ), strictly increasing times in seconds, matching values. LINEAR interpolation. No procedural idle/walk/run unless authored and tested. Explicit skin weights only; no automatic rig solver.

## CPU diagnostic render
Run `python scripts/render_clay.py project/export/character.glb project/renders/bind --size 384` for five fixed-scale actual native-GLB bind-pose clay views. The bounded standard-library rasterizer reads the exact GLB, shows triangle faces and darker backfaces, and records camera directions/coverage. For revisions pass `--camera-from` pointing to the accepted `views.json` and the same `--size` to avoid changing framing or scale. It cannot display PBR, textures, smooth normals, animation, transformations or arbitrary imported GLB; never use it as full G8/G9/G10 evidence.

## Limits and validation
Native compiler bounds aggregate 600k vertices, 300k triangles, 256 joints, 32 MiB texture budget and 100 MiB source; use tighter platform limits. It rejects many invalid indices, degenerate faces, folded quads, nonmanifold indexed edges, invalid UV ranges, seam pairs and weight sums; checks are limited (e.g. UV duplicates and self-intersection not detected). It exports a genuine GLB 2.0 with geometry, normals, UV0, materials, optional embedded textures and skinned nodes/animation. It does not supply general remeshing, UV atlas generation, normal/AO baking, tangent generation, high-poly sculpt, collisions, neural inference, PBR renderer or engine runtime. If tangent-space normal maps are used, validate importer tangent generation and parity; for bakes use compatible explicit tangents in an enhanced backend.

Keep part source IDs and hashes; freeze accepted parts and only modify target module plus necessary seam dependencies. Inspect actual GLB with `inspect_glb.py`; run Khronos Validator and reimport where available. Compiler report COMPILED_ONLY is not G0-G11 PASS. Visual review, UV checks, actual bake and skin/animation inspection remain required. Never label a low-quality parametric character AAA. If richer algorithms or renderer unavailable, return appropriate honest status.
