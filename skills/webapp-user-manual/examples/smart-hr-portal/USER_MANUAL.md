## 1. ภาพรวมระบบและวัตถุประสงค์ (System Overview)

**ระบบ SmartHR e-Leave Portal** เป็นระบบเว็บแอปพลิเคชันสำหรับอำนวยความสะดวกให้พนักงานสามารถยื่นคำขอลาประเภทต่างๆ (ลาพักร้อน, ลาป่วย, ลากิจ, ลาคลอด ฯลฯ), ตรวจสอบวันลาคงเหลือ, แนบเอกสารรับรองแพทย์ และติดตามสถานะการอนุมัติได้แบบ Real-time โดยไม่จำเป็นต้องใช้แบบฟอร์มกระดาษ

### วัตถุประสงค์หลักของระบบ:
- ลดขั้นตอนและระยะเวลาในการส่งต่อเอกสารใบลาไปยังหัวหน้างานและฝ่ายบุคคล
- พนักงานสามารถตรวจสอบสิทธิ์วันลาคงเหลือและปฏิทินทีมได้ทันที
- ส่งเสริมการทำงานแบบ Paperless และรองรับการทำงานแบบ Hybrid / Remote Working
- ผู้อนุมัติสามารถพิจารณาคำขอได้อย่างรวดเร็วผ่านหน้าจอเดียว พร้อมระบบแจ้งเตือนทางอีเมล

> [!NOTE]
> ระบบนี้ครอบคลุมกลุ่มผู้ใช้งาน 2 กลุ่มหลัก ได้แก่ **พนักงานทั่วไป (Employee)** และ **หัวหน้างาน/ผู้อนุมัติ (Supervisor / Manager)**

## 3. การเข้าสู่ระบบและการจัดการโปรไฟล์ (Authentication & Profile)

### 3.1 ขั้นตอนการเข้าสู่ระบบ (Sign In)
1. เปิดเว็บบราวเซอร์แล้วเข้าไปที่ `https://leave.company-portal.internal`
2. ระบบจะแสดงหน้าจอเข้าสู่ระบบ:
   - **ชื่อผู้ใช้งาน (Username / Corporate Email):** กรอกอีเมลองค์กร เช่น `somchai.s@company.com`
   - **รหัสผ่าน (Password):** รหัสผ่านบัญชีส่วนกลาง (Single Sign-On / Active Directory)
3. คลิกปุ่ม **[เข้าสู่ระบบ] (Sign In)**
4. หากองค์กรเปิดใช้งาน 2FA ให้ระบุรหัส OTP 6 หลักที่ได้รับผ่านแอป Authenticator แล้วคลิก **[ยืนยันรหัส]**

```text
+-------------------------------------------------------------+
|                     SmartHR e-Leave Portal                  |
|                                                             |
|   อีเมลองค์กร:   [ somchai.s@company.com                  ] |
|   รหัสผ่าน:      [ ********************                   ] |
|                                                             |
|   [x] จดจำฉันในระบบ           [ ลืมรหัสผ่าน? (Forgot) ]     |
|                                                             |
|                  +-----------------------+                  |
|                  |     [เข้าสู่ระบบ]     |                  |
|                  +-----------------------+                  |
+-------------------------------------------------------------+
```
*ภาพที่ 1: หน้าจอการเข้าสู่ระบบ SmartHR e-Leave Portal*

> [!WARNING]
> หากป้อนรหัสผ่านผิดเกิน 5 ครั้ง ระบบจะระงับการเข้าใช้งานชั่วคราวเป็นเวลา 15 นาที เพื่อป้องกันการบุกรุกความปลอดภัย หากลืมรหัสผ่าน ให้คลิกที่ **"ลืมรหัสผ่าน? (Forgot Password)"**

### 3.2 การตรวจสอบและแก้ไขโปรไฟล์ส่วนตัว
1. คลิกที่รูปโปรไฟล์ที่มุมขวาบนของหน้าจอ เลือก **เมนู "โปรไฟล์ส่วนตัว" (My Profile)**
2. ตรวจสอบข้อมูลสังกัด, แผนก, และชื่อหัวหน้างานผู้มีสิทธิ์อนุมัติ
3. หากข้อมูลหัวหน้างานไม่ถูกต้อง ให้คลิก **[แจ้งแก้ไขข้อมูลต้นสังกัด]** เพื่อประสานงานกับฝ่าย HR

## 5. ขั้นตอนการปฏิบัติงานหลัก (Core Workflows)

### 5.1 การยื่นคำขอลาออนไลน์ (Submit Leave Request)

ปฏิบัติตาม 4 ขั้นตอนง่ายๆ ดังนี้:

#### ขั้นตอนที่ 1: เปิดหน้าต่างสร้างคำขอ
- คลิกที่ปุ่ม **[+ ยื่นคำขอลาใหม่]** บนแดชบอร์ด หรือไปที่ **เมนู "จัดการการลา" > "ยื่นคำขอลาใหม่"**

#### ขั้นตอนที่ 2: กรอกรายละเอียดการลา
1. เลือก **ประเภทการลา** ในดรอปดาวน์ (เช่น ลาพักร้อน, ลาป่วย, ลากิจ)
2. เลือก **ช่วงเวลาที่ต้องการลา**:
   - ลาเต็มวัน: กำหนดวันที่เริ่มต้น และวันที่สิ้นสุด
   - ลาครึ่งวัน: เลือกตัวเลือก "ครึ่งวันเช้า" (08:30 - 12:00) หรือ "ครึ่งวันบ่าย" (13:00 - 17:30)
3. ระบบจะคำนวณจำนวนวันลาที่ใช้โดยอัตโนมัติ (หักวันหยุดประจำสัปดาห์และวันหยุดนักขัตฤกษ์ออกให้ทันที)
4. ระบุ **เหตุผลการลา** ในช่องหมายเหตุ
5. ระบุ **ผู้ปฏิบัติงานแทน (Handover Colleague)** เพื่อส่งต่องานเร่งด่วนในระหว่างลา

#### ขั้นตอนที่ 3: แนบเอกสารหลักฐาน (ถ้ามี)
- หากเป็นการลาป่วยตั้งแต่ 2 วันทำการขึ้นไป หรือลาคลอด/ลาบวช ให้คลิกที่กล่อง **[แนบไฟล์หลักฐาน]** หรือลากไฟล์ใบรับรองแพทย์มาวาง (รองรับไฟล์ `.pdf`, `.jpg`, `.png` ขนาดไม่เกิน 10 MB)

#### ขั้นตอนที่ 4: ยืนยันการส่งคำขอ
- คลิกปุ่ม **[ส่งคำขออนุมัติ] (Submit Request)**
- ระบบจะแสดงกล่องป๊อปอัปแจ้งยืนยัน:
  > *"ยื่นคำขอลาสำเร็จ! รหัสอ้างอิง: `REQ-2026-00412` ระบบได้ส่งการแจ้งเตือนไปยังหัวหน้างานของท่านเรียบร้อยแล้ว"*

> [!TIP]
> หากยังกรอกข้อมูลไม่ครบหรือยังไม่มีเอกสารแนบ สามารถคลิกปุ่ม **[บันทึกร่าง] (Save Draft)** ไว้ก่อนได้ โดยคำขอนี้จะยังไม่ถูกส่งไปรบกวนหัวหน้างาน

---

### 5.2 การยกเลิกคำขอลา (Cancel Leave Request)

พนักงานสามารถขอยกเลิกคำขอลาได้ตามเงื่อนไขดังนี้:

1. ไปที่ **เมนู "ประวัติการลาของฉัน"**
2. ค้นหารายการคำขอที่ต้องการยกเลิก
3. ตรวจสอบสถานะ:
   - **กรณีสถานะ "รออนุมัติ (Pending)":** สามารถคลิกปุ่ม **[ยกเลิกคำขอ]** ได้ทันทีโดยไม่ต้องรอหัวหน้างานอนุมัติ
   - **กรณีสถานะ "อนุมัติแล้ว (Approved)":** ให้คลิกปุ่ม **[ขอยกเลิกวันลา]** พร้อมระบุเหตุผล ระบบจะส่งคำขอยกเลิกไปให้หัวหน้างานกดยืนยันคืนสิทธิ์วันลาให้

> [!IMPORTANT]
> การยกเลิกวันลาที่ผ่านพ้นไปแล้ว (เลยวันที่ลามาแล้ว) จะต้องติดต่อฝ่ายบุคคล (HR) เพื่อดำเนินการปรับปรุงสิทธิ์เป็นกรณีพิเศษเท่านั้น

---

### 5.3 การพิจารณาอนุมัติคำขอ (สำหรับหัวหน้างาน / Approver)

หัวหน้างานสามารถตรวจสอบและอนุมัติคำขอของลูกทีมได้ 2 ช่องทาง:

#### ช่องทางที่ 1: ผ่านหน้าเว็บพอร์ทัล
1. ไปที่ **เมนู "รายการรออนุมัติ" (Pending Approvals)** ที่แถบด้านข้าง
2. ระบบจะแสดงรายการคำขอของลูกทีมในสังกัด
3. คลิกที่รายการเพื่อดูรายละเอียดเหตุผลการลาและตรวจสอบผู้ปฏิบัติงานแทน
4. ดำเนินการพิจารณา:
   - คลิกปุ่ม **[อนุมัติ] (Approve):** ระบบจะตัดยอดวันลาคงเหลือของพนักงาน และส่งอีเมลแจ้งผล
   - คลิกปุ่ม **[ส่งกลับแก้ไข] (Request Changes):** เพื่อให้พนักงานแก้ไขวันที่หรือรายละเอียด
   - คลิกปุ่ม **[ปฏิเสธ] (Reject):** ต้องระบุเหตุผลประกอบการปฏิเสธในช่องข้อความบังคับ

#### ช่องทางที่ 2: อนุมัติด่วนผ่านอีเมล (1-Click Email Action)
- เมื่อมีคำขอใหม่ ระบบจะส่งอีเมลแจ้งเตือนไปยังหัวหน้างาน โดยสามารถคลิกปุ่ม **[Approve]** หรือ **[Reject]** ในเนื้อหาอีเมลได้ทันทีโดยไม่ต้องล็อกอินเข้าหน้าเว็บ

| **วันที่สิ้นสุด (End Date)** | Date Picker | ✅ | ต้องไม่น้อยกว่าวันที่เริ่มต้น |

| **เหตุผลการลา (Reason)** | ข้อความยาว | ✅ | ระบุคำชี้แจง ความยาวอย่างน้อย 10 ตัวอักษร |
| **ผู้ปฏิบัติงานแทน** | ค้นหารายชื่อ | ✅ | พิมพ์ชื่อหรือรหัสพนักงานเพื่อนร่วมงานที่ตกลงฝากงาน |
| **เบอร์ติดต่อฉุกเฉิน** | ตัวเลข | ❌ | ระบุเบอร์โทรศัพท์ที่สามารถติดต่อได้กรณีเกิดเหตุเร่งด่วน |
| **เอกสารแนบ (Attachment)** | อัปโหลดไฟล์ | เงื่อนไข | บังคับแนบเมื่อลาป่วยเกิน 2 วันขึ้นไป (รองรับ PDF, JPG, PNG ขนาด ≤ 10MB) |

## 7. การค้นหา การตรวจสอบสิทธิลา และการส่งออกรายงาน (Search & Export)

### 7.1 การตรวจสอบประวัติการลา
- ไปที่ **เมนู "ประวัติการลา" (Leave History)**

  - **Adobe PDF (.pdf):** สำหรับพิมพ์เก็บเป็นหลักฐานลายลักษณ์อักษร

## 8. ปัญหาที่พบบ่อยและแนวทางแก้ไข (Troubleshooting & FAQs)

### Q1: วันลาคงเหลือในระบบไม่ตรงกับความเป็นจริง ต้องแก้ไขอย่างไร?
> **สาเหตุ:** อาจเกิดจากรอบการตัดยอดสิทธิ์ประจำปี หรือคำขอลาก่อนหน้ายังอยู่ในสถานะรออนุมัติ  
> **แนวทางแก้ไข:** ตรวจสอบในตารางประวัติว่ามีคำขอที่ค้างรอการอนุมัติอยู่หรือไม่ หากตรวจสอบแล้วยังไม่ถูกต้อง ให้คลิกปุ่ม **"แจ้งประสานงาน HR"** ที่อยู่ด้านล่างตารางวันลาคงเหลือ

### Q2: ยื่นใบลาแล้ว หัวหน้างานแจ้งว่าไม่เห็นคำขอในระบบ?
> **สาเหตุ:** พนักงานอาจกดปุ่ม "บันทึกร่าง (Save Draft)" แทนปุ่ม "ส่งคำขอ (Submit)" หรือสังกัดหัวหน้างานในระบบไม่ตรงกับสายบังคับบัญชาจริง  
> **แนวทางแก้ไข:** เข้าไปที่หน้าประวัติการลา หากสถานะขึ้นว่า **"ฉบับร่าง (Draft)"** ให้คลิกเข้าไปกดปุ่ม **[ส่งคำขออนุมัติ]** อีกครั้ง

### Q3: ไม่สามารถอัปโหลดไฟล์ใบรับรองแพทย์ได้?
> **สาเหตุ:** ขนาดไฟล์เกิน 10 MB หรือเป็นนามสกุลไฟล์ที่ไม่รองรับ  
> **แนวทางแก้ไข:** ตรวจสอบว่าไฟล์เป็นนามสกุล `.pdf`, `.jpg` หรือ `.png` และมีขนาดไม่เกิน 10 MB หากถ่ายภาพจากโทรศัพท์มือถือ ให้ปรับลดความละเอียดลงก่อนอัปโหลด

### Q4: หน้าจอแสดงผลค้าง หรือปุ่มกดยื่นคำขอไม่ตอบสนอง?
> **แนวทางแก้ไข:** ให้ทำการล้างแคชบราวเซอร์โดยกดปุ่ม <kbd>Ctrl</kbd> + <kbd>F5</kbd> (Windows) หรือ <kbd>Cmd</kbd> + <kbd>Shift</kbd> + <kbd>R</kbd> (Mac)
