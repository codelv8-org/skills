# IT & Web Application Manual Style Guide (แนวทางการใช้ภาษาและคำศัพท์)

เอกสารอ้างอิงคำศัพท์ การจัดรูปแบบ และข้อแนะนำสำหรับการเขียนคู่มือการใช้งานระบบ Web Application ภาษาไทย-อังกฤษ

---

## 1. หลักการใช้ภาษา (Tone of Voice & Principles)

1. **ใช้คำกริยาเชิงปฏิบัติการ (Action-Oriented):**
   - ใช้: "คลิกปุ่ม **[บันทึก]**", "เลือกเมนู", "กรอกข้อมูลในช่อง..."
   - หลีกเลี่ยงประโยคบอกเล่าเฉื่อยชา เช่น: "การบันทึกข้อมูลนั้นผู้ใช้จะต้องทำการกดลงไปที่ปุ่มบันทึก"
2. **คงความสุภาพและเป็นทางการอย่างพอเหมาะ:**
   - ใช้สรรพนามบุรุษที่สองแบบกลางๆ หรือใช้คำว่า "ผู้ใช้งาน" หรือ "ท่าน"
3. **คำทับศัพท์ที่นิยมใช้ในวงการไอที:**
   - Login -> เข้าสู่ระบบ (Log in)
   - Logout -> ออกจากระบบ (Log out)
   - Dashboard -> แดชบอร์ด (หรือหน้าจอภาพรวม)
   - Click -> คลิก
   - Download / Upload -> ดาวน์โหลด / อัปโหลด
   - Form -> แบบฟอร์ม
   - Dropdown -> ดรอปดาวน์ (หรือเมนูตัวเลือก)

## 2. พจนานุกรมคำศัพท์ UI มาตรฐาน (UI Terminology Glossary)

| ภาษาอังกฤษ | คำแปลภาษาไทยที่แนะนำ | ตัวอย่างประโยคในคู่มือ |
|---|---|---|
| **Sign in / Log in** | เข้าสู่ระบบ | ระบุชื่อผู้ใช้และรหัสผ่านเพื่อเข้าสู่ระบบ |
| **Sign out / Log out** | ออกจากระบบ | แนะนำให้ออกจากระบบทุกครั้งหลังเลิกใช้งาน |
| **Save / Submit** | บันทึกข้อมูล / ส่งข้อมูล | คลิกปุ่ม **[บันทึกข้อมูล]** เพื่อยืนยัน |
| **Cancel / Discard** | ยกเลิก / ละทิ้ง | คลิก **[ยกเลิก]** หากไม่ต้องการบันทึกการแก้ไข |
| **Edit / Modify** | แก้ไข | คลิกไอคอนดินสอเพื่อ **[แก้ไข]** ข้อมูล |
| **Delete / Remove** | ลบรายการ | ยืนยันการ **[ลบ]** ข้อมูลในกล่องข้อความเตือน |
| **Search / Filter** | ค้นหา / ตัวกรอง | ใช้ **แถบค้นหา** เพื่อพิมพ์ค้นหาชื่อเอกสาร |
| **Export / Import** | ส่งออก / นำเข้า | คลิก **[Export to Excel]** เพื่อดาวน์โหลดไฟล์ |
| **Attach file / Upload** | แนบไฟล์ / อัปโหลดไฟล์ | คลิก **[เลือกไฟล์]** หรือลากไฟล์มาวางในช่องแนบ |
| **Mandatory / Required** | ฟิลด์บังคับ / ข้อมูลจำเป็น | ช่องที่มีเครื่องหมายดอกจันสีแดง (*) เป็นข้อมูลที่จำเป็นต้องกรอก |
| **Status / Badge** | สถานะ | แถบสีแสดง **สถานะของคำขอ** เช่น "รออนุมัติ" |
| **Role / Permission** | บทบาท / สิทธิ์การใช้งาน | ผู้ใช้งานที่มีสิทธิ์ระดับ "ผู้ดูแลระบบ (Admin)" เท่านั้น |
| **Password reset** | รีเซ็ตรหัสผ่าน | เลือกลิงก์ **"ลืมรหัสผ่าน"** เพื่อตั้งรหัสผ่านใหม่ |

## 3. กฎเกณฑ์การจัดรูปแบบตัวอักษร (Typography & Formatting Rules)

1. **ชื่อปุ่มหรือสิ่งที่คลิกได้:**
   - ใช้เครื่องหมายวงเล็บเหลี่ยมหนา หรือเครื่องหมายคำพูดคู่หนา:
   - ตัวอย่าง: คลิกปุ่ม **[ถัดไป]** หรือกดปุ่ม **"Next"**
2. **ชื่อฟิลด์หรือคอลัมน์:**
   - ใช้เครื่องหมายคำพูดคู่หนา:
   - ตัวอย่าง: ในช่อง **"เบอร์โทรศัพท์ติดต่อ"**
3. **เส้นทางเมนูหลายระดับ:**
   - ใช้เครื่องหมายมากกว่า `>`:
   - ตัวอย่าง: ไปที่เมนู **"การเงิน" > "ใบเสร็จรับเงิน" > "ออกใบเสร็จใหม่"**
4. **คีย์ลัดบนแป้นพิมพ์:**
   - ใช้แท็ก `<kbd>`:
   - ตัวอย่าง: กด <kbd>Ctrl</kbd> + <kbd>P</kbd> เพื่อสั่งพิมพ์หน้าจอ
5. **ข้อความหรือโค้ดระบบ:**
   - ใช้ Backticks (code inline):
   - ตัวอย่าง: ตรวจสอบเลขที่อ้างอิง `INV-2026-999`

## 4. มาตรฐานการระบุภาพหน้าจอและภาพประกอบ (Visual Captions)

เมื่ออ้างอิงถึงหน้าจอในคู่มือ:
1. ตั้งชื่อไฟล์รูปภาพให้สื่อความหมาย เช่น `01-login-screen.png`, `02-dashboard-overview.png`
2. ใส่คำบรรยายใต้ภาพ พร้อมระบุเลขลำดับภาพ เช่น `ภาพที่ 1: หน้าจอแสดงรายละเอียด...`
3. ใช้หมายเลขล้อมรอบวงกลม `❶`, `❷`, `❸`, `❹`, `❺` อธิบายชี้จุดในภาพเสมอ เพื่อให้ผู้อ่านเข้าใจได้ทันทีโดยไม่ต้องเดา
