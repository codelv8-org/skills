# Anatomical UV and texture registration

## 1. Establish the atlas contract before texturing

Choose a licensed, anatomically credible head with good edge loops; fix clay anatomy first. Prefer template retopology/non-rigid mesh wrapping or registered scan transfer when repeated heads must share texture coordinates. A canonical atlas belongs to a particular topology/version, not to humans universally. Never import a flat face photo into a different atlas without projection/registration. A template's UV coordinates and a Blender vertex index do not necessarily survive a glTF exporter unchanged. Record final GLB mesh/primitive/triangle and barycentric anchors; distinguish subject-left from image-left. Keep `atlas_id`, final `uv_sha256` (exported index order plus UVs; not topology-invariant), candidate hash, source rights and atlas revision. For consistent eyebrow variants reuse the same atlas, then validate each head separately. If UV/topology changes, invalidate all dependent masks/maps/decal assets and rebake.

## 2. Seam design and UV quality

- Keep a continuous facial shell through forehead, eyebrows, eyelids, cheeks, nose/alar rim and lips where feasible. Put seams on rear scalp, behind ears, under jaw or at neck boundary. Ears/inner nostrils may require strategically placed separate islands. Use separate material/UV islands for cornea, sclera/iris, lashes, hair, oral interior; never paint these onto skin as substitutes for geometry.
- Apply rotation/scale, triangulate the exact runtime topology and preserve face loops. Mark seams, pin anatomical anchors when needed, use Angle Based/Conformal unwrap as appropriate, minimize stretch, average island scale and pack deliberately. Avoid accidental overlap/mirroring; deliberately mirrored non-skin materials must not be included in the unique skin atlas. Verify U/V orientation and handedness against a known labeled checker; Blender UV V-up differs from glTF texture coordinate V-down. In the validator `ccw` means positive signed area in numeric UV coordinates (not visual screen orientation), `cw` negative. Determine expected sign from verified template/checker, not the majority of a potentially wrong map.
- Use labeled directional checker with numbers, arrows and asymmetry; inspect front, both profiles, 3/4, nose underside, ear and lip close-ups. A checker that is square in the atlas but warped on the face is a distortion defect. Use heatmaps for local anisotropy and relative density; inspect worst triangles as well as p95. Do not treat a p95 pass as local quality proof. Local meter density is meaningful only with applied scene scale; different density targets can be deliberate, never silently relax limits. Use non-overlapping islands and 8–16 px padding at 2K as a starting point; inspect mip levels and bake dilation. Use head-local coordinates; don't compare differently scaled meshes.
- Export an uncompressed candidate GLB, select one unique skin material and one skin mesh. Run `scripts/validate_head_surface.py` on actual UV0. It checks positive-area triangle overlap (not shared edges), winding, degenerate and out-of-bounds triangles, UV Jacobian singular-value ratio and relative area density (engineering p95 limits 4x), and embedded maps. It produces heatmaps. No claim of exact coverage, padding distance, anatomical correspondence or 100% realism from metrics. Split skin material conventions require a future explicit per-atlas audit; do not combine unrelated atlas triangles.

## 3. Landmark registration and atlas locking

Use `assets/templates/surface_manifest.json`. Annotate each required feature independently on the actual exported 3D surface and final *base color* UV image. Use the GLB's mesh index, primitive index, triangle index (three indices per triangle) and nonnegative barycentric weights summing to one; interpolate UV0. `texture_uv` is the independently located feature in normalized image coordinates (u=x, v=y down). Annotate both brow ends/arch, inner/outer canthus, tip/ala/subnasale, lips/mouth corners, ears and hairline; choose actual anatomy, never copy interpolated UV to fake a matching texture annotation. If brows absent on purpose use registered brow mask/neutral brow anchor and document that source. Use an independently reviewed canonical atlas for identical topology; record reference landmarks before wrapping and separately inspect current projection. A 1% outer-eye UV span maximum is a strict project starting tolerance, not biometric science; inspect independent 3D/camera correspondence and local texture deformation. Inferred unseen features must be identified. Seam landmarks must use the intended island side. Inspect overlays and mirrored text for L/R reversal.

## 4. Projection and baking

If source photos exist: obtain permission and ideally calibrated front/profile/3/4/back images with neutral expression, controlled diffuse light, fixed exposure and white balance, optional cross-polarized diffuse and parallel-polarized reflectance. Align cameras in 3D; confirm landmarks and silhouette independently. Use z-buffer visibility, surface incidence and image-quality weights; mask eyelashes, hair, teeth, specular highlights, occlusions, extreme grazing angles. Reproject to the actual mesh then bake into locked UV0. Correct exposure/color across overlapping views, feather using visibility/confidence and remove shadows/highlights without removing actual pigmentation. Never project frontal photo through side/back skull; use licensed compatible scan/hand-painted plausible fill and mark inferred regions. Thin-plate-spline/piecewise affine warping can align registered 2D texture features only when anchored to a verified atlas; don't use as a substitute for 3D camera geometry. Cross-polarized acquisition helps isolate diffuse but single uncontrolled photos do not uniquely recover lighting, reflectance, geometry or unseen skin. Preserve asymmetric details where authorized. Avoid fake specular and AO in BaseColor.

For a scan: register a licensed base via correspondences and wrapping; compare normals, anatomy and silhouette; bake source color and high-to-low displacement/normal using appropriately tuned cage or ray distance per head/ear/lip part. Inspect missed rays and spikes, then dilate island padding. Build separate master 4K+ and runtime 2K atlases as practical budgets, not requirements. When only a generic original face is requested, use licensed scan/pigment sources or careful manual region painting, not a uniform procedural color/noise map.
