- [ใบเสนอราคา A4 1 หน้า](quotation-DEMO-QT-2026-001.pdf)
- [สไลด์ภาพรวมบริการ 16:9 จำนวน 6 หน้า](service-overview-DEMO-QT-2026-001.pdf)
- [ข้อมูลที่ใช้สร้างเอกสาร](quote-data.json) ต่อยอดจาก [ชุดข้อมูลตั้งต้น](../../assets/quote-data.example.json) โดยเพิ่มผังขั้นตอนจองคิวใน `presentation_diagrams`

ตัวอย่างมียอดรวม **69,000.00 บาท** สมมติให้ผู้เสนอราคาเป็นบุคคลธรรมดาที่ไม่ได้จดทะเบียน VAT และแบ่งชำระเป็น 3 งวด

| งวด | สัดส่วน | ยอด (บาท) |
| --- | ---: | ---: |
| เริ่มงาน | 30% | 20,700.00 |
| ส่ง Demo และ UAT | 40% | 27,600.00 |
| รับมอบ | 30% | 20,700.00 |

## ราคาอ้างอิงที่ตรวจเมื่อ 23 พฤศจิกายน 2026

- Bluewich เผยแพร่ราคาเริ่มต้น 50,000 บาทสำหรับเว็บที่มีระบบจองหรือสั่งซื้อ พร้อมหน้าจอจัดการ [บทความราคาของ Bluewich](https://bluewich.com/blog/website-cost-bangkok-2026/)
- OPEN / Studio เผยแพร่ราคาเริ่มต้น 90,000 บาทสำหรับเว็บที่มีระบบโต้ตอบ เช่น กระบวนการจองคิว และ 135,000 บาทสำหรับระบบงานภายใน [แพ็กเกจของ OPEN / Studio](https://openstudio.asia/packages)

ราคาของผู้ให้บริการอ้างอิงครอบคลุมขอบเขตต่างกัน ยอดในชุดสาธิตมาจากรายการงานสมมติ 4 รายการใน `quote-data.json`
