## D. ตรวจสอบข้อมูลก่อนเริ่ม

- [ ] ชื่อผู้ให้บริการและช่องทางติดต่อถูกต้อง
- [ ] สถานะ VAT ได้ยืนยันแล้ว
- [ ] รู้ว่ามี Logo ไฟล์ที่เปิดอ่านได้จริงหรือยอมใช้ข้อความแทน
- [ ] อ่านเกณฑ์ราคาที่ Skill แนะนำและปรับตามต้นทุนจริงแล้ว
