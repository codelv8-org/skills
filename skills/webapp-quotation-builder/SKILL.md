# Web App Quotation Builder

สำหรับประเมินราคาและเสนอแผนส่งมอบ Web App/PWA ใช้ภาษาไทยเป็นค่าเริ่มต้น ใช้ไทย/อังกฤษตามบริบท และระบุสกุลเงิน THB กับวันที่ให้ชัดเจน

## 1. เตรียมโปรไฟล์ผู้เสนอราคาและข้อมูลอ้างอิง

1. สำหรับใบเสนอราคาใหม่ ให้แสดง [แบบฟอร์ม Markdown](templates/provider-profile.template.md) ฉบับใหม่และกรอกข้อมูลที่ตรวจสอบได้ ระบุช่องที่ต้องยืนยัน ขอให้ผู้ใช้ยืนยันข้อมูลผู้เสนอราคาก่อนนำมาใช้ซ้ำ ตรวจสอบลูกค้าและข้อมูลโครงการทุกครั้งก่อนนำข้อมูลเดิมมาใช้ กรณีแก้ไขใบเสนอราคา ให้ถามเฉพาะข้อมูลที่เปลี่ยนและตรวจราคา/ภาษีอีกครั้งเมื่อข้อมูลเก่าหรือวันออกเอกสารเปลี่ยน
2. ตรวจราคาอย่างน้อยสองแหล่งอิสระที่ยังเปิดดูได้สำหรับใบเสนอราคาใหม่ทุกฉบับ ระบุวันที่ตรวจ ขอบเขตบริการ และลิงก์ในแบบฟอร์มก่อนส่งให้ผู้ใช้กรอก แยกราคาเว็บสำเร็จรูปจากงานพัฒนาระบบเฉพาะ ระบุข้อมูลที่ตรวจซ้ำไม่ได้เป็น `STALE/UNVERIFIED` พร้อมวันที่ตรวจล่าสุด อ่าน [แนวทางราคา](references/price-research.md) และ [แนวทางภาษีไทย](references/thai-legal-checks.md)
3. ขอชื่อและสถานะทางกฎหมายของผู้เสนอราคา ที่อยู่ ผู้ติดต่อ ไฟล์โลโก้ที่เข้าถึงได้ สถานะ VAT ราคาขั้นต่ำหรือเป้ากำไร เงื่อนไขการค้า และข้อยกเว้น
4. ยืนยันเฉพาะช่องสำคัญที่ยังขาด แล้วแจ้ง **“กรอกข้อมูลผู้ให้บริการเรียบร้อยแล้ว พิมพ์ ‘ทำต่อ’ เพื่อเริ่มประเมินราคาโครงการ”** รอ `ทำต่อ` หรือคำสั่งเทียบเท่าก่อนเริ่มถามรายละเอียดโครงการ ให้เก็บโปรไฟล์ในบริบทของงานตามขอบเขตที่ได้รับอนุญาต

## 2. เก็บรายละเอียดโครงการ

- ใช้ [ชุดคำถาม](references/question-bank.md) ถามครั้งละ 2–4 ข้อ แต่ละข้อมีตัวเลือกที่ชัดเจนอย่างน้อย 3 ข้อ พร้อม `Other` ให้ระบุเอง และเลือก “ยังไม่แน่ใจ” เพิ่มได้เมื่อเหมาะสม รองรับคำตอบแบบ `1B, 2Other: ...` ใช้คำตอบเดิมในใบเสนอราคาฉบับนี้และข้ามคำถามที่ไม่เกี่ยวข้อง
- ยืนยันข้อมูลลูกค้าและผู้ติดต่อ เป้าหมาย ประเภทระบบ โมดูล/จำนวน/ขั้นตอน จำนวนผู้ใช้และสิทธิ์ UI/UX การย้ายข้อมูล การเชื่อมต่อ ความอ่อนไหวและความปลอดภัย โฮสติ้งและการส่งมอบ ระยะเวลา/งบประมาณ กรรมสิทธิ์ซอร์สโค้ด รอบแก้/ตรวจรับ ประกันและบริการ ค่าใช้จ่ายภายนอก งวดชำระ VAT และ WHT หลีกเลี่ยงการขอข้อมูลลับหรือ production credentials
- หากขอบเขต เวลา งบประมาณ หรืองานด้านความปลอดภัยขัดกัน ให้ตกลงสมมติฐาน ข้อยกเว้น และขอบเขตที่ส่งมอบได้ก่อนคำนวณราคา

## 3. คำนวณและตรวจเงื่อนไข

- รวมงานเป็น 3–7 รายการตามขอบเขต คำนวณจำนวน × ราคาต่อหน่วย จัดทำต้นทุนภายในจากจำนวนวันทำงาน ค่าใช้จ่ายภายนอก ค่าเผื่อ และเป้ากำไรเมื่อเกี่ยวข้อง ถ้าตั้งเป้า gross margin ให้ใช้ `cost / (1 - gross margin)` อ้างอิงช่วงราคาตลาดตามงานใกล้เคียง
- รักษาราคาขั้นต่ำของผู้เสนอราคาและเสนอลดขอบเขตตามงบเมื่อจำเป็น ใช้ราคาคงที่เมื่อขอบเขตและเงื่อนไขตรวจรับชัดเจน กรณีอื่นระบุว่าเป็นงบประมาณเบื้องต้นหรือข้อเสนอสำหรับช่วงสำรวจ
- ยืนยันสถานะจดทะเบียนและอัตรา VAT จากข้อมูลที่ตรวจสอบแล้วก่อนออกเอกสารจริง คำนวณ WHT ตามเงื่อนไขผู้จ่ายและผู้รับ และแสดงผลต่อยอดรับชำระแยกจากส่วนลด ดู [แนวทางภาษีไทย](references/thai-legal-checks.md) ขอผู้เชี่ยวชาญทบทวนกรณีเฉพาะ
- ระบุเลขที่ วันที่ออก/หมดอายุ ผู้เสนอราคา ลูกค้า ขอบเขต รายการและยอดเงิน VAT ตามกรณี ยอดรวม ระยะเวลา งวดชำระพร้อมเงื่อนไขครบ 100% การตรวจรับ การแก้ไขงานเพิ่มเติม กรรมสิทธิ์ การส่งมอบ การรับประกัน งานที่รวม/ไม่รวม ข้อมูลติดต่อ และพื้นที่อนุมัติ ใช้ข้อความ `ใบเสนอราคา (QUOTATION) — ไม่ใช่ใบกำกับภาษี`
- ถามเฉพาะข้อมูลสำคัญที่ยังขาด เมื่อยืนยันครบแล้วให้สร้างไฟล์ได้เลย

## 4. สร้างและตรวจ PDF

ใช้ `Sarabun` กับข้อความไทยและอังกฤษทั้งหมดในใบเสนอราคา A4 และสไลด์ ทั้งไฟล์ต้นฉบับและ PDF ติดตั้งฟอนต์ `Sarabun` ในสภาพแวดล้อมที่สร้างไฟล์ก่อนเริ่ม และตรวจว่าทั้งสอง PDF ฝังฟอนต์จริง หากพบการแทนฟอนต์ ให้แก้การตั้งค่าและส่งออกใหม่ก่อนส่งมอบ

ใช้ [JSON ตัวอย่าง](assets/quote-data.example.json) เป็นแบบโครงสร้าง สร้าง `quote-data.json` จากข้อมูลที่ยืนยันแล้ว ใช้พาธรูปในเครื่องและเลี่ยงข้อมูลลับหรือรายละเอียดต้นทุนภายในในเอกสารลูกค้า ใช้โลโก้และไฟล์ที่ได้รับอนุญาต

อ่าน [โครงสร้างองค์ประกอบ](references/slide-component-architecture.md), [ระบบออกแบบสไลด์](references/slide-design-system.md), [รูปแบบแผนภาพและ Stepper](references/diagram-stepper-patterns.md) และ [เกณฑ์ตรวจสไลด์](references/slide-qa-checklist.md) ก่อนจัดหน้า ใช้ `SlideUI.render(slide, tree, frame)` จาก [slide_components.js](scripts/slide_components.js) เพื่อวาง Grid, Stack, Card, Stepper และ Diagram เป็นข้อความและรูปทรง PPTX ที่แก้ไขได้ แสดงงวดชำระตามสัดส่วนของยอดจริง แบ่งหน้าต่อเมื่อเนื้อหาแน่นและรักษาขนาดข้อความหลักอย่างน้อย 16 pt

```powershell
.\scripts\generate.ps1 --input .\quote-data.json --out-dir .\quote-results
```

```bash
bash scripts/generate.sh --input ./quote-data.json --out-dir ./quote-results
```

เครื่องมือสร้าง PDF ต้องมี Python, `playwright`, Chromium ใน `PATH` (`chromium`, `chromium-browser`, `google-chrome` หรือ `chrome`), `pymupdf`, Node.js, `pptxgenjs`, LibreOffice ใน `PATH` (`soffice.com` บน Windows หรือ `soffice`) และ [ฟอนต์ Sarabun](https://github.com/google/fonts/tree/main/ofl/sarabun) หากชุด `pptxgenjs_helpers` อยู่คนละตำแหน่งกับค่าเริ่มต้น `/home/oai/skills/slides/pptxgenjs_helpers/index.js` ให้ตั้ง `SLIDES_HELPERS` เป็นพาธเต็มของ `index.js` จากชุดเครื่องมือที่เชื่อถือได้ หาก runtime ไม่พร้อม ใช้เครื่องมือสร้าง PDF/สไลด์ที่ตรวจผลตามเกณฑ์เดียวกันได้

- ใช้ [pricing.py](scripts/pricing.py) ตรวจข้อมูลและปัดเศษเป็นสตางค์ [generate.py](scripts/generate.py) กับ [build_slides.js](scripts/build_slides.js) สร้างไฟล์และตรวจขนาดหน้า
- ส่งมอบ `quotation-<number>.pdf` ขนาด A4 แนวตั้งหนึ่งหน้า และ `service-overview-<number>.pdf` แนวนอน 16:9 ปกติ 5 หน้า ขยายได้ถึง 12 หน้า เก็บไฟล์ PPTX/HTML/JSON เป็นไฟล์ระหว่างทำงาน ส่งให้ผู้ใช้เมื่อร้องขอ
- ตัวสร้างเรียก [slide_preflight.py](scripts/slide_preflight.py) หลังส่งออก PDF เพื่อตรวจขนาดหน้า ข้อความ และความครบถ้วนของเนื้อหา เมื่อแก้ตัวสร้างให้รัน `python scripts/test_pricing.py`, `python scripts/test_components.py` และ `python scripts/test_slides.py` พร้อมตรวจภาพ PDF ทุกหน้า
- ตรวจเกณฑ์ใน [รายการ QA](references/output-qa.md) เทียบยอดรวม VAT งวดชำระ ชื่อลูกค้า วันหมดอายุ กรรมสิทธิ์ และเงื่อนไขของทั้งสองไฟล์ เปิดภาพเรนเดอร์เพื่อตรวจฟอนต์ไทยและข้อความล้น หาก A4 เกินหนึ่งหน้าให้ปรับการจัดกลุ่มและย่อข้อความโดยคงเงื่อนไขสำคัญ
- ส่งลิงก์ PDF ทั้งสองไฟล์พร้อมยอดเสนอราคา สถานะ VAT อายุใบเสนอราคา และสมมติฐานที่เกี่ยวข้อง สำหรับข้อมูลทดลอง ให้ระบุ **ตัวอย่างเท่านั้น ไม่ใช่ใบเสนอราคาจริง**

ตัวอย่างคำขอ “ช่วยออกใบเสนอราคา Web App ระบบจองคิวคลินิก” ให้เริ่มจากตรวจแหล่งราคาและภาษี กรอกแบบฟอร์มผู้เสนอราคา รอ `ทำต่อ` แล้วเก็บรายละเอียดระบบจองคิวก่อนคำนวณและออก PDF
