# LINE Seed Sans TH

Fonts are unmodified LINE Seed Sans TH V1.003 Regular/Bold WOFF2 files from the official Thai package:
https://seed.line.me/src/images/fonts/LINE_Seed_Sans_TH.zip

Copyright embedded in the Thai font: © LY Corporation.
The official LINE Seed website states that all LINE Seed fonts use SIL Open Font License 1.1:
https://seed.line.me/

Full license text is reproduced unchanged in OFL.txt from the official LINE Seed repository:
https://github.com/line/seed/blob/main/OFL.txt

The local page uses these files through @font-face and makes no runtime font request to an external service.
